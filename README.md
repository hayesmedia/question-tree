# Question Tree

Internal questionnaire and diagram editor. Run `npm start` with Node.js 20+; the local server uses port 3000. No dependency installation is required. Run `npm test` for validation, source migration, exports, routing and authentication checks; `npm run build` assembles the deployment assets in `_site`.

## Questionnaire data

`data/questionnaire-v3.json` is the original uploaded package, preserved without changing its question data. It contains **149 questions in 10 stages**, including 107 single-select questions, 42 typed inputs and 39 question visibility rules. Its description says 134 questions, but the actual question array contains 149.

`flows/texas-questionnaire.json` is recreated exclusively from this JSON. It includes complete prompts, option values/labels/help/unknown flags/order, explanations, beginner help, response types, persona, route codes, URLs, placeholders, units, limits, required/unknown settings, order and parsed visibility branches. All original question records and stage definitions are retained. Run `node scripts/import-questionnaire.js` to regenerate it; generation has no screenshot input.

Each stage has its JSON title and ordered questions. Long arrows join related questions and connect stages as well as showing the local condition cards. Teal connectors show question order within the stage. Conditions are labeled directly on the arrows using only their values, such as **Yes**, **No**, **Yes / Maybe** or **Tenant**. Generated yellow condition notes are removed. Full AND/OR expressions and original branch JSON remain in question/connector Properties; stage configuration remains in group Properties. Long question dependencies are restored using unique matches between field meanings and question wording, and are explicitly marked **inferred** with dashed purple lines. These associations do not populate canonical mappings or executable answer destinations. Core stages connect in exported order; dashed navigation links connect the explicitly selected route-validation sections to Due Diligence and Closing. The JSON does not export their entry predicates. Screenshot routes, the screenshot Texas stop card and screenshot-only settings remain excluded. Q191 remains exactly **New question**, as provided.

Connectors default to **4 px** on the canvas and in PDF diagrams. Canvas strokes retain their visual thickness when zooming out. The connection inspector can adjust individual widths.

## Existing work and JSON recreation

Existing browser/team projects receive a backed-up migration that removes old source-owned screenshot connectors and unchanged screenshot-only settings. It keeps card positions, custom wording/settings, custom-created connectors, edited destinations, deleted questions and existing group memberships. Generated rule notes and their note-only arrows are removed during migration; user-created notes are preserved. The old screenshot baseline and legacy converter are retained solely to distinguish old source data from user edits during migration; they are not used to generate the current workflow.

**Question data → Recreate canvas from JSON only** replaces the active canvas with the clean JSON reconstruction and its generated layout, after saving a backup. This also clears local custom additions from the active canvas; they remain in the backup. Use it when a clean reconstruction is desired instead of retaining a previous layout.

**Question data** downloads the original package. Per-card **Review uploaded source details** applies source details explicitly. **Import** accepts editor projects (replace after backup) or questionnaire packages (safe merge). A failed browser backup blocks updates. **Backup** downloads the previous project; export **JSON** for an independent copy. Manually imported packages remain authoritative across reloads.

## Editor controls

Hold Space while dragging to pan. Hold **Shift + mouse wheel** to pan horizontally without changing zoom. Drag empty canvas to box-select cards/groups the selection rectangle touches; Shift adds to the selection. In **Select (S)**, clicking or dragging a grouped card selects/moves the whole group. **Double-click the group or one of its cards** to enter isolated group editing: drag empty space to box-select only its cards, then drag any selected card to move that selection. An Editing group bar and highlighted boundary identify the active group; outside cards/groups/lines are dimmed and cannot be selected, and the sidebar lists only group members. Use **Exit group** or **Escape** to return to the workspace. Entering and exiting groups preserves the current canvas position and zoom, including any panning done inside the group. New/duplicated cards stay in the active group. **Grab (G)** pans the canvas with a hand cursor. Drag group labels to move whole groups; Shift-click group labels or group backgrounds to select several groups. Inside group editing, Shift-drag adds member cards to the selection; outside, box-selection selects whole groups or ungrouped cards. Click empty space to deselect. Sidebar entries include original question IDs, and search accepts IDs or complete prompt text. Group names appear on cards and boundaries. Dragging cards/groups or a selection box near a canvas edge automatically pans in that direction, including while the pointer stays still. Moving cards keeps the current viewport in place and remembers their positions as the focus for reload. **Center diagrams** fits the selection, or all cards when nothing is selected; tall flows can zoom out far enough to fit without the old minimum-zoom clipping. Centering changes the view, not saved diagram coordinates.

The toolbar provides Select/Grab/Connector (S/G/C), undo/redo, duplicate (Ctrl/Cmd+D), delete, group/ungroup, alignment, distribution, fill, connector color, grid and snapping. Shapes include rectangles, diamonds, ellipses and notes. Cards support resize, rotation, font size/style and text/border colors. Select a connector to edit labels, arrows, line style/width, routing or bend points. Automatic routing uses a bounded obstacle search with an exterior-lane fallback; dense layouts may need manual bends.

Screenshot uploads are session-only references, not automatic OCR imports. The dark/light preference persists in browser storage. This editor does not provide full Lucidchart parity or live simultaneous editing.

## Preview and exports

**Test questionnaire** supports select, text, currency, percentage, number, year and date answers. It uses stage/question order when no explicit answer destination exists. Visibility rules can evaluate supplied values keyed by their exact field codes; the export does not map question answers to those fields, so the preview shows unresolved conditions for review rather than inventing mappings or hiding questions. Because strategy-entry conditions are not exported, choose a strategy section for the test explicitly. The stage’s stop configuration is retained exactly in its JSON definition; a screenshot-derived Yes/No stop route is not added. Typed values are temporary preview responses and do not change the editor's source records.

**Project CSV** and **Project PDF** cover the entire project. CSV includes configuration, raw source question records, stage definitions, metadata, groups, source warnings, connectors and formatting. PDF includes tiled diagrams, full prompts and question details, help, options, source issues and stage rules. Choose **Print / Save as PDF** in the report. Project JSON retains the original package. Uploaded screenshot images are not embedded in exports.

Production: https://question-tree.dry-bonus-373b.workers.dev. Cloudflare's Git integration deploys pushes to `main`; GitHub Actions runs tests/build only. Set the deploy command to `npm run deploy`, which builds before deploying. `wrangler.jsonc` publishes `_site`, never the repository root.

Set **SITE_PASSWORD** as a Cloudflare Worker secret. The Worker protects all static assets and the team API. Sessions last 24 hours with signed Secure/HttpOnly/SameSite=Strict cookies. Changing the password invalidates sessions. Sign out preserves browser work. A missing password fails closed. Never commit the password or send it through chat. Remove separate Worker-specific Cloudflare Access protection if only the shared password is desired, after verifying the password gate works. Loading first backs up local work; revision checks reject stale saves. Five previous revisions are retained server-side. No local project is uploaded automatically. Use `wrangler dev` with a test password to test the protected team API locally.

## Main green connections
Solid green connections between groups use outward-facing card ports and exterior routes around group bounds (including their labels) and intervening cards. Their thicker stroke and background outline make them easier to follow. Green connections within the same group keep their existing paths, and dotted connections keep their routing/style. Manual bend points take precedence. Overlapping groups may leave no completely clear route; use manual bends in those cases. The PDF uses the same group-aware routing. These changes redraw the view without changing saved card positions or connector endpoints.

The card spacing cleanup runs once per project: it leaves horizontal positions and card order intact and adds at least 90 canvas units between nearby cards inside each group, using their rendered dimensions. It creates a backup before moving cards and can be undone. Subsequent manual overlap is allowed; refresh does not repeat the cleanup.

Card fill, text color, and border color in Properties apply to every selected card. Select groups to change Group color in Properties; it updates their border/label and translucent background while leaving member card colors alone. Group color is also available inside isolated group editing.

In Answers & destinations, drag the **Move answer** handle to insert an answer above or below another row. The insertion line shows its new position. Alt + Up/Down on the handle also reorders it. The answer's value, destination, help, connector formatting, and other metadata move together; current sortOrder, card display, preview, saved project, CSV, and PDF follow the new order. Undo/Redo restores the entire change. The original uploaded source package remains an archival copy.

Click a connector to open its bottom-right Connection summary: source question ID and full prompt, connection label/arrow, and destination question ID and full prompt. Click either question to center and briefly highlight that card without closing the summary. The × button closes the summary; selecting something else also dismisses it.
